# 短剧导演类 Skill 收藏

本文档用于沉淀适合“短剧创作 / 导演思维 / 分镜设计 / 拍摄手法 / 镜头语言”的 SkillHub skill，作为后续能力拆解、产品设计和方法论研究的个人文档资产。

## 检索目标

本次筛选标准不是泛化的“短视频脚本生成”，而是更聚焦以下能力：

- 短剧创作
- 导演思维
- 分镜设计
- 镜头语言
- 景别与机位
- 运镜与调度
- 拍摄执行
- 节奏控制
- AI 短剧导演工作流

## 第一梯队：最值得重点研究

### 1. `director-writer`

- 定位：导演型写作系统
- 适用范围：影视文案、脚本创作、宣传片、纪录片、短视频、招商片、人物片、城市形象片等全流程协作
- 核心能力：
  - 脚本创作
  - 分镜设计
  - 镜头稿
  - 拍摄执行
  - 母稿拆版
  - 稿件诊断
  - 剪辑逻辑
- 价值判断：
  - 这是非常强的“导演 + 编剧 + 执行稿转化”型 skill
  - 不只是写文案，更偏影视创作的全流程方法
- 推荐原因：
  - 适合研究导演如何把内容从概念推进到执行稿
  - 对你做短剧系统特别有参考意义

### 2. `ai-short-drama-director`

- 定位：AI 短剧导演
- 核心能力：
  - 剧本分析
  - 人物 / 场景生图
  - 分镜设计
  - 首帧生成
  - 视频生成
  - 后期合成
- 价值判断：
  - 这是和你项目方向最贴近的 skill 之一
  - 它不是单点能力，而是端到端流水线
- 推荐原因：
  - 适合直接参考 AI 短剧生成 workflow
  - 很适合作为你后续产品模块拆解蓝本

### 3. `hf-drama-storyboard-script`

- 定位：短剧文字分镜脚本
- 核心能力：
  - 短剧镜头拆解
  - 景别设计
  - 镜头调度
  - 视效说明
  - 剪辑节奏
  - 卖点标签整合
  - 可拍摄分镜 JSON 输出
- 价值判断：
  - 这一项非常专业，已经接近导演实际分镜脚本层
  - 不只是“写画面”，而是考虑节奏、调度和可拍摄性
- 推荐原因：
  - 对短剧导演系统非常重要
  - 很适合研究“结构化分镜输出”的方式

### 4. `video-cinematography`

- 定位：电影感拍摄与镜头运动
- 核心能力：
  - 镜头运动
  - 运镜技巧
  - 景别
  - 推拉摇移
  - 电影感构图
  - 分镜脚本支持
- 价值判断：
  - 这是偏“专业导演 / 摄影知识”的核心补充 skill
  - 如果你想补导演知识，这个非常值得研究
- 推荐原因：
  - 适合为短剧系统补齐镜头语言与摄影基础知识层
  - 可用于建立运镜语法、构图语法和镜头模板库

### 5. `script-to-storyboard`

- 定位：剧本转分镜脚本表格
- 核心能力：
  - 将剧本文本解析为结构化分镜
  - 根据场景描述生成拍摄计划
  - 输出标准分镜表格
- 结构字段：
  - 镜号
  - 景别 / 拍摄角度
  - 画面内容
  - 出场人物
  - 场景
  - 音效
- 价值判断：
  - 很适合把自然语言剧本转成导演 / 制片可用的执行结构
- 推荐原因：
  - 可作为“剧本 → 分镜表”的标准格式参考

## 第二梯队：偏 AI 导演与分镜强化

### 1. `madstory`

- 定位：广告级影视分镜设计引擎
- 核心能力：
  - 构图
  - 运镜
  - 光影
  - 声音
  - 多镜头叙事
  - 一镜到底
  - 爆款复刻
  - 短剧批量生产
- 价值判断：
  - 更偏高规格视觉导演表达
  - 适合借鉴高级镜头描述和多维度分镜设计方法

### 2. `seedance-director`

- 定位：AI 短视频导演
- 核心能力：
  - 创意构思
  - 素材准备
  - 分镜设计
  - 生成 production-ready prompts
- 价值判断：
  - 偏 Seedance 平台落地，但导演工作流值得参考

### 3. `director-beat-split`

- 定位：短剧节奏拆分导演
- 核心能力：
  - 精确拆分节奏
  - 控制剧情推进
  - 控制情绪信息释放
  - 监督后续制作
- 价值判断：
  - 非常适合短剧，尤其是强节奏、强钩子的竖屏内容

### 4. `story-video-skill`

- 定位：故事转视频导演分镜 skill
- 核心能力：
  - 从故事文本转视频
  - 分镜生成
  - 编剧分析
  - 导演分镜
- 价值判断：
  - 适合作为剧情到镜头方案的中间层参考

### 5. `storyboard-sketch-narrative`

- 定位：分镜故事板创作助手
- 核心能力：
  - 多宫格分镜故事板
  - 单镜头导演模式
  - 角色圣经管理
- 价值判断：
  - 更适合视觉规划和角色一致性管理

## 第三梯队：偏短剧生产链路

### 1. `ai-video-industrial-gen`
- 价值：偏电影级短视频工业化生成，适合商业化视频流程参考

### 2. `ai-drama-prompt-factory`
- 价值：偏提示词工厂，适合研究短剧全链路提示词组织结构

### 3. `video-script-generator`
- 价值：偏通用短视频脚本 + 分镜生成，适合实用型脚本结构研究

## 推荐优先下载研究顺序

建议优先研究以下 5 个：

1. `hf-drama-storyboard-script`
2. `video-cinematography`
3. `director-writer`
4. `ai-short-drama-director`
5. `script-to-storyboard`

- 导演知识层：`video-cinematography`
- 导演执行层：`director-writer`
- 短剧分镜层：`hf-drama-storyboard-script`
- 剧本转执行结构层：`script-to-storyboard`
- AI 短剧工作流层：`ai-short-drama-director`

## 简要结论

如果你的目标是做一个更专业的短剧生成系统，不能只靠“爆款脚本”和“短视频文案”类 skill，还需要补上：

- 导演语言
- 镜头语言
- 景别与机位体系
- 运镜规则
- 分镜表结构
- 节奏拆分逻辑
- 拍摄执行转换能力

从 SkillHub 当前结果看，以上能力最接近的参考集合，就是本文档里这一组导演类 skill。
