## 一、优先收藏：最贴近当前需求

### 1. `viral-script-writer`

- 定位：爆款口播视频脚本创作专家
- 主要能力：
  - 生成符合“黄金 3 秒”原则的短视频脚本
  - 支持抖音、TikTok、YouTube、B站、X.com 等平台适配
  - 更偏口播稿、短视频文案、视频脚本
- 适用场景：
  - 生成短视频脚本
  - 优化开场钩子
  - 多平台脚本改写
- 收藏理由：
  - 很适合借鉴为“口播脚本生成器”“短视频结构脚本器”
  - 与爆款脚本生成方向高度相关

### 2. `viral-hook-weaponizer`

- 定位：爆款开头钩子生成器
- 主要能力：
  - 一次生成多个简短 viral hooks
  - 强调心理触发和短内容高互动开头
  - 适合短句式高冲击表达
- 适用场景：
  - 短剧首句台词
  - 首屏字幕
  - 开场口播
  - 标题式开场改写
- 收藏理由：
  - 对短剧 / 短视频的前 1~3 秒非常关键
  - 可直接作为“爆款 hook 库”的参考来源

### 3. `viral-video-predictor`

- 定位：短视频爆款预测与脚本诊断工具
- 主要能力：
  - 输入脚本后分析爆款概率
  - 分析 hook、节奏、情绪曲线
  - 输出优化建议
- 适用场景：
  - 对已有脚本做预审
  - 发现掉点问题
  - 对多个版本做优劣判断
- 收藏理由：
  - 很适合做“脚本质检器”“上线前评分器”“A/B 文案预判模块”

### 4. `viral-content-miner`

- 定位：热点分析与爆款挖掘工具
- 主要能力：
  - 自动挖掘抖音、小红书、公众号、快手、B站、微博、视频号、知乎、新闻门户等平台爆款内容
  - 聚合热门关键词
  - 分析爆款规律
  - 提供创作角度建议
- 适用场景：
  - 选题策划
  - 热点追踪
  - 内容定位
  - 竞品分析
- 收藏理由：
  - 适合作为“选题雷达”“热点捕手”“爆款题材池”的参考

### 5. `viral-video-studio`

- 定位：短视频创作全流程 workflow
- 主要能力：
  - 分析参考爆款视频 URL
  - 反向拆解其结构与打法
  - 面向 TikTok、Instagram Reels、YouTube Shorts 做短内容创作
- 适用场景：
  - 竞品爆款拆解
  - 从参考样本反推脚本结构
  - 建立可复制的短视频工作流
- 收藏理由：
  - 更接近“参考爆款 → 拆解 → 仿写 → 再生产”的工作方式
  - 非常适合你后续做产品 workflow 设计

### 6. `video-script-generator`

- 定位：短视频脚本和分镜生成器
- 主要能力：
  - 输入产品 / 主题描述、目标受众、时长
  - 输出完整脚本 + 分镜结构
  - 支持痛点-解决、反转剧情、before-after 等模板
- 适用场景：
  - 生成短视频脚本
  - 生成 storyboard
  - 结构化输出给后续视频生产环节使用
- 收藏理由：
  - 与“短剧脚本 + 分镜自动化”高度相关
  - 适合沉淀成规范化 JSON / YAML 输出结构

### 7. `video-producer`

- 定位：短视频一键生成技能
- 主要能力：
  - 调用 video-director 进行画面规划
  - 生成 AI 素材
  - 进行 TTS 配音
  - 完成视频渲染并输出 MP4
- 适用场景：
  - 从脚本到成片的自动生产
  - 快速验证内容方案
  - 批量生成标准化视频
- 收藏理由：
  - 很适合作为“AI 短视频生产流水线”的参考
  - 偏生产型而不是单纯写作型

## 二、平台向收藏：TikTok 相关

### 1. `tiktok`
- 定位：TikTok 增长系统
- 重点：策略、钩子、脚本、留存设计、分析反馈
- 价值：适合做 TikTok 平台总控参考

### 2. `tiktok-growth`
- 定位：TikTok 内容策略与脚本生成器
- 重点：hook 公式、viral script structure、趋势利用
- 价值：适合做平台特化脚本层能力

### 3. `tiktok-content-pipeline`
- 定位：TikTok 内容生产与排程流水线
- 重点：轮播内容创作、智能排程、发布、数据反馈优化
- 价值：适合做发布链路参考

### 4. `tiktok-content-ideas-refresh`
- 定位：TikTok 内容创意刷新器
- 重点：从评论、失败内容、现有受众中刷新创意角度
- 价值：适合做账号持续更新和创意迭代

### 5. `tiktok-short-video`
- 定位：TikTok 短视频带货创作指南
- 重点：内容策划、拍摄技巧、剪辑优化、流量获取、标签策略、数据分析
- 价值：更适合偏带货与转化型视频场景

## 三、可补充关注的其他 viral 方向

### 1. `viral-title-generator`
- 用途：生成高点击标题
- 价值：适合补充标题层优化，不是主脚本层

### 2. `viral-video-analysis`
- 用途：分析视频为什么表现不佳，并给出创作者反馈
- 价值：适合做复盘诊断模块参考

### 3. `viral-decoder`
- 用途：拆解 TikTok / Reels / Shorts 爆款电商内容
- 价值：更偏电商转化和内容策略提炼

### 4. `viral-content-expert`
- 用途：面向抖音、视频号、小红书做爆款二创全流程创作
- 价值：适合中文平台二创内容方向
